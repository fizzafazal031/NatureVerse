
# NatureVerse 🌿

AI-Based Plant and Animal Learning Application using Flutter.

## Project Overview

NatureVerse is a mobile application designed to help users explore plants and animals, learn about nature, and identify plant diseases.

## Features

- Plant Categories and Information
- Animal Categories and Information
- Plant Disease Detection
- Image Identification
- Favorites
- Nature Quiz
- Personal Notes
- User Profile
- Dark and Light Theme

## Technology

- Flutter
- Dart
- Android Studio
